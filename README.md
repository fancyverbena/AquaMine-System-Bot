# AquaMine System Bot

AquaMine サービス向けの Discord 管理ボットです。

## 機能
- サーバー管理用コマンド（現在開発中）
- 例：`!ping` で疎通確認

## 必要なもの
- [Discord Bot トークン](https://discord.com/developers/applications)
- Docker または Python 3.12 以上

## セットアップ（Docker を使う場合）
1. リポジトリをクローン
   ```bash
   git clone https://github.com/あなたのユーザー名/AquaMine-System-Bot.git
   cd AquaMine-System-Bot
